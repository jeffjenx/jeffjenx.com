Maintenance Checklist

  • Monthly Check Google Search Console for new structured data or coverage issues → search.google.com/search-console
  • Monthly Review GitHub Issues for open items on jeffjenx.com → github.com/jeffjenx/jeffjenx.com/issues
  • Quarterly Run URL liveness audit on all active vendor listings → CLI: cd tools/health && node index.js — exits 1 if any URLs dead. See tools/health/README.md
  • As needed After editing products.json — sync changes to Zazzle and Redbubble → Open Sync Tool → export updated titles/descriptions/tags → paste into platform dashboards → mark synced
  • As needed After adding a new product — verify it appears correctly on store page → jeffjenx.com → confirm card renders, vendor link works, picker fires if multi-vendor
  • As needed If a vendor URL goes dead — deactivate in products.json, do not delete → Set active: false on the vendor entry + add a note field explaining why. Preserves audit history.
